# Shell Desktop

Web3 Dev Studio - Tauri Desktop Application

## 开发

```bash
cd desktop

# 安装依赖
pnpm install

# 开发模式
pnpm dev

# 构建
pnpm build

# Tauri 开发
pnpm tauri dev
```

## 依赖

- Node.js 18+
- pnpm
- Rust
- Tauri CLI (`cargo install tauri-cli`)

## 功能

- OpenCode Server 集成
- Web3 命令执行 (forge, anchor, hardhat)
- 测试报告查看
- 模板快速创建
