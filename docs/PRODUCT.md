# Web3 DevOps 产品定位

## 一句话定位

> AI-powered Web3 contract debugging and deployment automation.

---

## 核心价值主张

**不是写合约的工具，是修合约的工具。**

---

## 目标用户

1. **智能合约开发者** — 频繁调试、修复 bug、部署测试
2. **Web3 创业团队** — 需要快速迭代但没有专业 DevOps
3. **安全审计辅助** — 自动化修复已知漏洞

---

## 解决的问题

| 痛点 | 现状 | 我们的方案 |
|------|------|------------|
| 合约测试失败不知从何修 | 看错误日志、猜原因 | AI 读报告 + 自动修复 |
| 部署后安全问题 | 依赖外部审计 | 部署前自动扫描 + 修复 |
| 多链部署繁琐 | 手动配置每条链 | 一键多链部署 |

---

## 产品架构

```
OpenCrabs (AI Agent)
    ↓ 调用
shell-run (确定性执行)
    ↓ 输出
reports/*.json (结构化结果)
    ↓ 决策
AI Agent 读取报告 → 决定下一步
```

**关键设计**：
- 所有动作输出 JSON，不依赖 stdout
- Agent 决策基于报告，不是猜测
- 失败可归因、可重放

---

## 核心工作流

```
Contract → Test → [Fail] → Fix → Test → [Pass] → Deploy → Report
```

每一步都写 JSON 报告，AI 根据报告决定下一步。

## 路线图 (90天)

### Phase 1: 核心闭环 (0-30天)
- [ ] web3_test + web3_report_read 集成
- [ ] 单一合约模板 (EVM Vault) 端到端
- [ ] 本地 CLI 可用

### Phase 2: 自动化修复 (30-60天)
- [ ] AI 根据报告自动生成修复代码
- [ ] 修复后自动重测
- [ ] 支持 Solana 合约

### Phase 3: 多链部署 (60-90天)
- [ ] 一键多链部署 (anvil / sepolia / mainnet)
- [ ] 自动安全扫描 + 修复
- [ ] GitHub Actions 集成

## 团队用这个向投资人说的版本

> 我们在解决一个具体问题：智能合约的调试和修复。
> 
> 现状是 Web3 开发者花 70% 时间在调试，而不是写代码。
